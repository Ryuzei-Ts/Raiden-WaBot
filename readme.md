### **`Información importante`**

**Raiden WaBot es un bot de WhatsApp basado en **`Node.js`** que utiliza la librería @whiskeysockets/baileys**

**Inspirado en el personaje Raiden de Genshin Impact**

### **`Funciones`**

**MAIN** — Información básica del bot: ID, creador, estado, info, ping y menú.

**DOWNLOAD** — Descargas de Instagram, letras de canciones, Pinterest, audio y video de YouTube, Spotify y TikTok.

**PROFILE** — Gestión del perfil: matrimonio, divorcio, historial, foto de perfil, cumpleaños, descripción y género.

**ADMIN** — Herramientas de administración de grupos: abrir/cerrar, enlaces, kick, promote, tagall, mute, antilink y modo solo admins.

**STICKERS** — Creación, personalización y búsqueda de stickers (incluye estilo BRAT y Sticker.ly).

**TOOLS** — Utilidades varias: IA conversacional, lectura de mensajes "ver una vez" y conversión de sticker a imagen.

**ECONOMY** — Sistema económico completo: balance, ranking, apuestas, crímenes, depósitos, retiros, trabajo, diario y robos.

**ANIME**— Más de 40 comandos de reacciones anime: besos, abrazos, caricias, bailes, emociones y acciones interactivas.

**LOGO** — Generador de logos con múltiples estilos: alas, neón, glitch, gaming, anime, PUBG, Matrix y más.

> Nota: Raiden-Bot en desarrollo activo. ¡Reporta cualquier problema al creador para una solución rápida!

### **`INSTALACIÓN`**

> Nota: Copie y pegue los comandos en Termux uno por uno.

```bash
termux-setup-storage
```

```bash
apt update && apt upgrade && pkg install -y git nodejs ffmpeg imagemagick yarn
```

```bash
git clone https://github.com/Ryuzei-Ts/Raiden-WaBot && cd Raiden-WaBot
```

```bash
yarn install
```

```bash
npm install --no-bin-links
```

```bash
npm update
```

```bash
npm start
```

> Si aparece (Y/I/N/O/D/Z) [default=N] ? use la letra "y" + "ENTER" para continuar con la instalación

### **✰ En caso de que no funcione**

> Si después de instalar el bot en Termux y iniciar la sesión del bot

```bash
cd && cd Raiden-WaBot && rm -rf Session && npm run qr
```

> Esto funciona para generar un nuevo código:

```bash
cd && cd Raiden-WaBot && rm -rf Session && npm run code
```

### **Solución de Problemas**

· Problemas con el QR: Reinicia Termux, verifica tu conexión o ejecuta npm run qr.
· Bot No Responde: Asegúrate de que tu cuenta de WhatsApp esté activa y revisa los logs en la terminal.
· Errores de Dependencias: Elimina la carpeta **`node_modules`** y ejecuta **`npm install`** nuevamente.
